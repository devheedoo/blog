# 환영합니다!

안녕하세요! 제 기술 블로그에 오신 것을 환영합니다.

## 이 블로그에 대해

이 블로그는 React, Vite, Tailwind CSS로 구축되었으며, GitHub Pages를 통해 자동으로 배포됩니다.

### 주요 기능

- **마크다운 기반**: 모든 글은 마크다운 형식으로 작성됩니다
- **태그 시스템**: 태그를 통해 관련 글들을 쉽게 찾을 수 있습니다
- **검색 기능**: 제목이나 설명으로 글을 검색할 수 있습니다
- **자동 배포**: Git push만으로 자동으로 배포됩니다

## 기술 스택

이 블로그는 다음 기술들을 사용합니다:

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- React Markdown
- GitHub Actions

## 코드 예시

```typescript
function greet(name: string): string {
  return `안녕하세요, ${name}님!`
}

console.log(greet('개발자'))
```
